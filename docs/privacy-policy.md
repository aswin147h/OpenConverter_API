# Privacy policy

OpenConvert uploads are used only to perform the requested conversion. Source files
and generated outputs are stored temporarily and automatically deleted after the
configured retention period, which is one hour by default.

The service does not intentionally log document text, document contents, or personal
filenames. Job identifiers are random, unguessable values and do not contain file names.

Users should not upload confidential, legally restricted, password-protected, or
illegal content. Public deployments should use HTTPS and private storage.
